📡 DNS برای مسدودسازی آپدیت خودکار

این مقادیر را در تنظیمات شبکه کنسول وارد کنید تا از آپدیت ناخواسته جلوگیری شود:

DNS اصلی — Relapse/PS5 45.56.67.85
DNS جایگزین — Raw13G/PS4 62.210.38.117
DNS دوم — TheGate 165.227.83.145
DNS سوم — پشتیبان 192.241.221.79
💡 دستورالعمل:
🔹 PS5: تنظیمات → شبکه → تنظیمات اتصال اینترنت → سفارشی → DNS دستی → اصلی و جایگزین را وارد کنید → «اتصال اینترنت» را یک بار خاموش و روشن کنید → به «راهنمای کاربری» بروید و لینک میزبان را باز کنید.
🔹 PS4: تنظیمات → شبکه → تنظیمات اتصال اینترنت → سفارشی → DNS دستی → مقادیر را وارد کنید → مرورگر اینترنت را باز کرده و لینک میزبان را وارد کنید.
⚠️ اگر یک میزبان وصل نشد، از میزبان دیگری استفاده کنید. گاهی ۲-۳ بار تلاش لازم است.

📖 راهنمای گام‌به‌گام

۱️⃣ بررسی فریم‌ور: تنظیمات → سیستم → اطلاعات سیستم → شماره نسخه را یادداشت کنید. اگر بالاتر از ۱۳.۶۰ (PS5) یا ۱۳.۵۲ (PS4) است، هنوز پشتیبانی نمی‌شود ❌

۲️⃣ غیرفعال‌سازی آپدیت: تنظیمات → سیستم → آپدیت خودکار → همه گزینه‌ها را خاموش کنید ✅

۳️⃣ تنظیم DNS: تنظیمات → شبکه → سفارشی → DNS دستی → مقادیر بالا را وارد کنید ✅

۴️⃣ باز کردن میزبان: PS5: «راهنمای کاربری» → لینک میزبان را وارد کنید. PS4: «مرورگر اینترنت» → لینک را وارد کنید ✅

۵️⃣ اجرای اکسپلویت: صفحه بارگذاری می‌شود → منتظر بمانید (گاهی چند بار تکرار لازم است) → پیام موفقیت ظاهر می‌شود ✅

۶️⃣ فعال‌سازی GoldHEN/etaHEN: منو ظاهر می‌شود → گزینه مربوط به فعال‌سازی را انتخاب کنید → منتظر بمانید تا کنسول ری‌استارت یا منو باز شود ✅

۷️⃣ نصب بازی‌ها: تنظیمات → اشکال‌زدایی → نصب بسته → فایل PKG را از حافظه خارجی انتخاب و نصب کنید ✅

⚠️ نکته مهم: این روش «موقت» است — پس از هر بار خاموش و روشن کردن کنسول، مراحل ۴ تا ۶ را تکرار کنید. هرگز به PSN متصل نشوید تا از مسدودسازی جلوگیری کنید!
